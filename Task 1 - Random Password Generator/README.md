# Task 1 - Random Password Generator

## Objective

The objective of this task was to build a Random Password Generator in Python that generates strong and secure passwords based on user-defined requirements.

## Features

- Generates random passwords based on selected length.
- Supports uppercase letters.
- Supports lowercase letters.
- Supports numbers.
- Supports special characters.
- Validates minimum password length.
- Ensures at least two character types are selected.
- Allows the user to generate another password.
- Includes a GUI version with password generation controls.
- Supports copying the generated password to the clipboard.
- Provides an option to exclude ambiguous characters.

## Technologies Used

- Python
- random
- string
- secrets
- tkinter
- pyperclip

## Implementation

The project contains both a command-line version and an advanced GUI version.

The command-line version allows the user to enter the desired password length and select character types.

The GUI version provides controls for password length, character types, ambiguous character exclusion, password generation, and clipboard copying.

## Outcome

A functional Random Password Generator was successfully developed and tested. The application generates passwords according to the selected requirements and provides both command-line and GUI-based functionality.
