# OIBSIP Python Internship Projects

This repository contains the Python projects developed during my Oasis Infobyte Python Programming Internship.

## Projects

### Task 1 - Random Password Generator

A Python-based password generator with both command-line and GUI versions.

**Technologies:** Python, random, string, secrets, tkinter, pyperclip

**Features:**
- Strong random password generation
- Custom password length
- Multiple character types
- Input validation
- GUI controls
- Clipboard integration
- Ambiguous character exclusion

### Task 2 - Weather App

A Python weather application that retrieves current weather information using the OpenWeatherMap API.

**Technologies:** Python, Requests, JSON, OpenWeatherMap API

**Features:**
- City-based weather search
- Temperature in Celsius and Fahrenheit
- Humidity
- Weather description
- Wind speed
- Error handling
- Request timeout handling

### Task 3 - Chat Application

A real-time two-user chat application built using Python socket programming and threading.

**Technologies:** Python, Socket Programming, Threading, TCP/IP, Datetime

**Features:**
- Two-client communication
- Real-time messaging
- Timestamps
- Sender names
- Client disconnection handling
- Exit option

## Internship Tasks

All three projects were developed, tested, and documented as part of the Python Programming Internship.
